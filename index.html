设置

账本设置：每公里电耗配置、数据同步与大模型识别引擎。

使用步骤
电脑：打开本页面填写订单 → 点「导出数据到文件」得到 json 文件。
手机：把 json 文件传到手机 → 打开本 App → 点右上角设置 → 「从文件导入数据」选择该文件。
从微信导入：好友把 json 发到微信 → 点「从微信导入」打开微信 → 在聊天中长按 json 文件 →「其他应用打开」→ 选择「顺风账本」即可。导入按记录合并，不会清空已有数据。

☁️ 云端同步 订单 + 地点

订单、地点定位缓存与地点合并关系实时对齐服务器（改后约 2 秒自动推送，断网时暂存、恢复后自动补推）。识图 API、提示词、每公里电耗等设置仅存手机本机。

⚡ 每公里电耗配置

利润 = 总收入 − 总里程 × 每公里电耗。用于统计栏目中的利润计算，扣除电费、损耗等成本后的实际收益。
