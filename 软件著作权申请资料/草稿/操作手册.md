## 二、说明

顺风账本软件 V1.0适用于出行服务配套软件 / 网约车顺风车司机个人经营记账工具场景。用户进入系统后，可以围绕实际工作内容完成账号进入、业务创建、过程查看、结果确认和资料管理等操作。

日常使用时，使用滴滴、高德等顺风车平台接单的网约车/顺风车司机、单日订单量较大、需要快速记账并了解自身收入、利润、里程等经营情况的独立司机可以按照页面提示从入口进入相应页面，查看当前业务状态，并根据页面中的按钮、输入框、列表或弹窗继续处理。司机每天接到大量平台订单，逐笔手动登记耗时费力。本软件通过智能大智能服务识别订单截图，自动提取车费、时间、起终点、人数、拼座/独享等信息并一键入账，同时提供里程/耗时估算与多维经营统计，全部数据本地存储、不上传服务器。

顺风账本是一款面向网约车/顺风车司机的个人经营收支记账 Android 应用，通过拍照识别订单截图自动入账，并提供里程估算与经营数据统计，满足司机日常记账与经营分析需求。

本手册用于说明软件的用途、功能特点、运行要求和页面操作流程。各功能章节按用户能够看到的页面、入口、按钮、输入项、提示信息和处理结果进行说明。

## 三、功能特点

用户可在配置大智能服务引擎页面配置识别订单图片与估算里程耗时所需的两个大智能服务数据通道，是首次使用前必须完成的准备工作。页面上的识图大智能服务与识路大智能服务两个配置分组，每组包含数据通道地址、智能服务名称、API Key 输入框，预设提示词查看与修改区域，以及连接测试按钮会集中呈现当前可操作内容，用户处理完成后可以看到连接测试成功后显示连通成功提示，配置即保存生效和失败时显示具体错误信息，用户可据此修正输入。

在识别订单截图页面中，用户主要处理从订单截图自动提取订单信息并一键入账，替代逐笔手动填写。系统把OCR 进度面板（读取图片、加载识别引擎、识别文字、解析订单四个步骤和进度条）、确认预览卡片（平台、日期、时间、总车费、奖励、起点、终点、人数、类型、里程、耗时）、取消与确认入账按钮放在当前操作区域，处理结束后会反馈识别进度随四个步骤推进，解析完成后预览卡片逐项填充，确认后订单出现在收入流水列表并同步刷新首页与小页面组成部分数据。

手工记一笔页面关注的是手动新增一条订单记录，适用于截图识别不便或需要补充修改的订单。用户通过订单编辑表单，包含日期、时间、平台、总车费、奖励、起点、终点、人数、车型类型、里程、耗时等输入项，以及保存与取消按钮和当检测到与已有订单重复时显示重复订单提示确认当前状态，并在操作结束后获得保存成功后新订单出现在流水列表对应日期分组中，首页今日收入、统计与小页面组成部分同步更新和重复订单会弹出提示供司机选择继续保存或返回修改。

用户可在首页经营看板页面一屏展示当天经营概况，让司机无需翻页即可掌握今日收入与近期趋势。页面上的今日订单数、今日收入大数字（整数与小数拆分展示）、与昨日收入对比（涨跌数值与升跌箭头）、本周收入与出车天数、本月收入与出车天数、日期与星期信息、识别订单与记一笔的快捷入口按钮会集中呈现当前可操作内容，用户处理完成后可以看到今日收入按整数与小数拆分放大展示，与昨日对比显示涨跌箭头与差额和新增、编辑或删除订单后，看板上的订单数、收入与本周本月汇总即时更新，出车天数按有订单记录的自然日累加统计，让司机打开软件第一眼即可掌握当天经营概况。

在收入流水页面中，用户主要处理按日期分组浏览全部订单，查看每笔订单明细并支持修改删除。系统把按日期分组的订单列表，每日分组显示分组收入小计，每条订单显示平台色点、时间、起点到终点、金额、每公里单价和顶部有订单总数标记与平台筛选入口放在当前操作区域，处理结束后会反馈订单按日期自动分组聚合显示收入小计，编辑或删除后列表、首页与统计数据同步更新。

日历统计页面关注的是以日历形式回顾历史每日订单与收入。用户通过月历网格，每个日期格显示当日订单数与收入，今天以特殊底色突出、格子以深浅底纹反映当日单量多少、页面底部显示当月总收入、总订单数与出车天数汇总和顶部提供上个月/下个月切换按钮与返回当前月入口确认当前状态，并在操作结束后获得日历逐格展示每日订单数与收入，单量多的日期以更深底色突出，今天日期有独立标记、切换月份后整个网格与底部汇总重新计算和点击具体日期弹出现场订单列表，可查看该日各平台订单与收入合计，从日历页即可完成历史订单的快速核对。

用户可在数据洞察页面对一段时间内的经营数据进行汇总统计与可视化分析，帮助司机评估盈利水平。页面上的统计范围切换（按天数）、总收入、利润、客单价、总里程、单数、天数等指标卡片、利润按每公里电耗成本估算和平台收入占比环图、每日收入趋势折线图、里程分布与耗时分布柱状图会集中呈现当前可操作内容，用户处理完成后可以看到切换统计范围后所有指标与图表同步重算刷新，利润扣减电耗成本后展示率与图形比例。

在出行足迹页面中，用户主要处理从地点维度分析常用起终点，形成常用地点词云、出行路网与黄金线路榜，帮助司机了解高频区域。系统把地点词云（按单数或收入切换模式、放大拖拽缩放全屏）、出行路网地图（高德地图上的上车点与下车点及连线）、黄金线路榜（高频线路排名）、地点管理列表（各地点上下车次数、定位状态、重新定位与合并操作）放在当前操作区域，处理结束后会反馈词云字号反映地点频次，路网地图绘制上车点、下车点与线路连线，线路榜按单数排序，地点管理展示定位状态与次数并支持重新定位与合并。

## 四、系统要求

| 系统要求 | 最低配置 | 推荐配置 |
| --- | --- | --- |
| 操作系统 | Android 6.0（API 23）及以上，手机或平板均可 | Android 10 及以上主流智能手机 |
| 网络 | 可联网调用大智能服务识别服务与高德地图服务 | 稳定的移动网络或 Wi-Fi |
| 存储 | 本地存储空间用于订单数据与 OCR 识别智能服务文件 | 预留 200MB 以上可用空间 |
| 使用场景 | 适合每日订单量较大的网约车顺风车司机在手机上日常使用 | 日常接单期间随拍随记 |

请确保实际运行环境满足以上要求，以保证顺风账本软件能够正常打开页面、提交操作和展示处理结果。若部署方式、客户端形态或服务器环境与本表不同，应以实际确认的申请表环境字段为准。

## 五、配置大智能服务引擎

用户可在配置大智能服务引擎页面配置识别订单图片与估算里程耗时所需的两个大智能服务数据通道，是首次使用前必须完成的准备工作。用户可以通过启动软件后点击首屏右上角设置入口进入设置页，在设置页中上下滑动找到识别引擎相关配置区。

司机第一次安装软件，或在更换大智能服务服务商、数据通道地址变化后，需要设置正确的数据通道地址、智能服务名称和 API Key。

用户在配置大智能服务引擎页面会看到识图大智能服务与识路大智能服务两个配置分组，每组包含数据通道地址、智能服务名称、API Key 输入框，预设提示词查看与修改区域，以及连接测试按钮等信息，并可依据页面显示继续处理。

使用该功能时，用户先进入设置页，找到识图大智能服务配置分组，随后在数据通道地址、智能服务名称、API Key 三个输入框中分别填入大智能服务服务信息，接着核对预设提示词，按需查看或修改识别规则，之后点击连接测试按钮，等待连通性检测结果，最后按同样方式配置识路大智能服务，两个智能服务均可正常连接后即可开始使用。

页面会按照数据通道地址、智能服务名称、API Key 为必填项，填写错误时连接测试会返回失败并提示原因和识别提示词为模板内容，可直接修改但需保持 JSON 输出结构约定等规则限制或提示用户。处理结束后，用户可以看到连接测试成功后显示连通成功提示，配置即保存生效和失败时显示具体错误信息，用户可据此修正输入。

## 六、识别订单截图

用户可在识别订单截图页面从订单截图自动提取订单信息并一键入账，替代逐笔手动填写。用户可以通过首页点击识别订单按钮，或通过页面提供的选择与拍摄入口选取订单截图。

司机完成一单出行后，拍下或截取平台订单完成页，希望快速把车费、时间、起终点等信息记入账本。

该部分提供OCR 进度面板（读取图片、加载识别引擎、识别文字、解析订单四个步骤和进度条）、确认预览卡片（平台、日期、时间、总车费、奖励、起点、终点、人数、类型、里程、耗时）、取消与确认入账按钮等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先在首页点击识别订单，随后拍摄一张订单截图，或从相册选择已有截图，接着等待 OCR 读取图片文字，首次使用需等待中文识别智能服务加载，之后大智能服务解析出订单信息后在确认预览卡片中逐项展示，再核对各项信息，如里程耗时缺失可点击重新估算，最后点击确认入账，订单即写入账本。

如果不满足未在设置页完成大智能服务配置时，识别流程会提示先前往设置配置、图片清晰度不足导致无法读取文字时，会提示识别失败并允许重试和识别出的信息可在入账前修改等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括识别进度随四个步骤推进，解析完成后预览卡片逐项填充，确认后订单出现在收入流水列表并同步刷新首页与小页面组成部分数据。

## 七、手工记一笔

用户可在手工记一笔页面手动新增一条订单记录，适用于截图识别不便或需要补充修改的订单。用户可以通过首页点击记一笔按钮，或点击流水列表中已有订单进入编辑。

订单截图模糊无法识别、司机想手动补录历史订单、或对识别结果进行修正时使用。

页面上主要呈现订单编辑表单，包含日期、时间、平台、总车费、奖励、起点、终点、人数、车型类型、里程、耗时等输入项，以及保存与取消按钮和当检测到与已有订单重复时显示重复订单提示等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先打开记一笔弹窗，随后填写日期、时间并选择平台，接着输入总车费与奖励金额，之后填写起点与终点，再选择人数与车型类型，填写或估算里程与耗时，最后点击保存。

操作过程中需要注意车费、日期等关键字段必填、保存时自动检测同年同日同起点终点同人数的重复订单，重复则提示确认和金额输入自动保留两位小数，耗时支持分钟数字输入。操作完成后，系统会显示保存成功后新订单出现在流水列表对应日期分组中，首页今日收入、统计与小页面组成部分同步更新和重复订单会弹出提示供司机选择继续保存或返回修改。

## 八、首页经营看板

用户可在首页经营看板页面一屏展示当天经营概况，让司机无需翻页即可掌握今日收入与近期趋势。用户可以通过启动软件即显示首页看板。

司机每天打开软件的第一屏，用于快速了解今天接了多少单、赚了多少、相比昨日是升是降，以及本周本月的累计情况。

用户在首页经营看板页面会看到今日订单数、今日收入大数字（整数与小数拆分展示）、与昨日收入对比（涨跌数值与升跌箭头）、本周收入与出车天数、本月收入与出车天数、日期与星期信息、识别订单与记一笔的快捷入口按钮等信息，并可依据页面显示继续处理。

使用该功能时，用户先启动软件即显示首页经营看板，先看今日订单数与今日收入大数字，随后查看与昨日同期对比的涨跌数值，判断今天经营走势，接着查看本周、本月累计收入与出车天数，掌握近期经营节奏，最后点击识别订单按钮可直接进入截图识别入账流程，点击记一笔按钮可手动新增订单，回到看板后数据自动刷新。

处理结束后，用户可以看到今日收入按整数与小数拆分放大展示，与昨日对比显示涨跌箭头与差额和新增、编辑或删除订单后，看板上的订单数、收入与本周本月汇总即时更新，出车天数按有订单记录的自然日累加统计，让司机打开软件第一眼即可掌握当天经营概况。

## 九、收入流水

用户可在收入流水页面按日期分组浏览全部订单，查看每笔订单明细并支持修改删除。用户点击底部标签栏的流水标签进入收入流水页。

司机需要回顾某天接了多少单、核对某笔订单金额是否录错、或修正起终点与里程时使用。

该部分提供按日期分组的订单列表，每日分组显示分组收入小计，每条订单显示平台色点、时间、起点到终点、金额、每公里单价和顶部有订单总数标记与平台筛选入口等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先进入流水页查看分组订单，随后按平台筛选查看高德或滴滴订单，接着点击某条订单查看详情或进入编辑，最后对录错的订单执行删除操作。

如果不满足删除订单需要确认，避免误删和日期分组按日期倒序排列等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括订单按日期自动分组聚合显示收入小计，编辑或删除后列表、首页与统计数据同步更新。

## 十、日历统计

用户可在日历统计页面以日历形式回顾历史每日订单与收入。用户点击底部标签栏的日历标签进入日历统计页。

司机想查看某一天或某一月接了多少单、收入多少，特别是隔几天后的补录与核对。

页面上主要呈现月历网格，每个日期格显示当日订单数与收入，今天以特殊底色突出、格子以深浅底纹反映当日单量多少、页面底部显示当月总收入、总订单数与出车天数汇总和顶部提供上个月/下个月切换按钮与返回当前月入口等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先点击底部标签栏的日历标签进入日历统计页，默认显示当前月份的每日订单与收入，随后通过上个月、下个月按钮切换月份，回顾任意历史月份的记录，接着观察当月的单数较多的日期，了解出车节奏，最后点击某个带数据的日期，下钻查看该日订单明细列表。

操作过程中需要注意无订单的日期格子显示为空态，不显示金额和切换月份后汇总栏同步更新为对应月份的数据。操作完成后，系统会显示日历逐格展示每日订单数与收入，单量多的日期以更深底色突出，今天日期有独立标记、切换月份后整个网格与底部汇总重新计算和点击具体日期弹出现场订单列表，可查看该日各平台订单与收入合计，从日历页即可完成历史订单的快速核对。

## 十一、数据洞察

用户可在数据洞察页面对一段时间内的经营数据进行汇总统计与可视化分析，帮助司机评估盈利水平。用户点击底部标签栏的统计标签进入数据洞察页。

司机想了解最近 7 天、30 天或更长周期的总收入、利润、客单价、里程与平台构成，判断经营成效。

用户在数据洞察页面会看到统计范围切换（按天数）、总收入、利润、客单价、总里程、单数、天数等指标卡片、利润按每公里电耗成本估算和平台收入占比环图、每日收入趋势折线图、里程分布与耗时分布柱状图等信息，并可依据页面显示继续处理。

使用该功能时，用户先进入数据洞察页，随后选择统计范围（如近7天、近30天），接着查看总利润、客单价等核心指标，之后查看高德与滴滴收入占比与每日趋势，最后查看里程与耗时分布了解订单结构。

页面会按照利润估算依赖设置中配置的每公里电耗，未配置时按默认值计算和统计范围为自然日前推 N 天等规则限制或提示用户。处理结束后，用户可以看到切换统计范围后所有指标与图表同步重算刷新，利润扣减电耗成本后展示率与图形比例。

## 十二、出行足迹

用户可在出行足迹页面从地点维度分析常用起终点，形成常用地点词云、出行路网与黄金线路榜，帮助司机了解高频区域。用户点击底部标签栏的足迹标签进入出行足迹页。

司机想看看自己经常在哪里接单上车、在哪里下车，哪些线路跑得最多，或对地点坐标进行核对调整。

该部分提供地点词云（按单数或收入切换模式、放大拖拽缩放全屏）、出行路网地图（高德地图上的上车点与下车点及连线）、黄金线路榜（高频线路排名）、地点管理列表（各地点上下车次数、定位状态、重新定位与合并操作）等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先进入足迹页查看地点词云，切换按单数或按收入排序，随后查看出行路网地图上的上下车地点分布，接着查看黄金线路榜了解高频线路，最后进入地点管理核对地点定位，对定位不准的地点重新定位，对同一地点的不同叫法执行合并。

## 十四、数据备份与恢复

用户可在数据备份与恢复页面把账本数据导出为备份文件，换机或重装时恢复，保障记账数据不丢失。用户可以通过设置页提供导出备份与从备份导入入口，也支持从微信接收的 JSON 文件直接导入。

司机更换手机、重装软件或担心数据丢失时，先导出备份，再在新设备或重新安装后导入恢复。

用户在数据备份与恢复页面会看到导出按钮、从备份文件导入按钮、从微信导入入口、导入结果提示等信息，并可依据页面显示继续处理。

使用该功能时，用户先在设置页点击导出备份，选择保存位置，随后将备份文件发送到新手机（如通过微信），接着在新设备上打开收到的备份文件或从文件导入，最后确认导入后数据完整恢复。

页面会按照导入会覆盖当前记录，需确认和备份文件格式需为软件导出的 JSON 结构等规则限制或提示用户。处理结束后，用户可以看到导出成功生成 JSON 备份文件到下载目录，导入成功后订单、地点缓存与智能服务配置全部恢复，界面数据随即刷新。

## 十五、典型使用流程

用户完成一次完整业务时，通常先进入顺风账本软件，再选择或创建业务对象，随后按照页面提示处理内容并查看结果。

首次使用：先进入设置页配置识图与识路大智能服务，分别填入数据通道地址、智能服务名称与 API Key 并完成连接测试；日常入账：从首页拍摄或选择订单截图，OCR 读取文字后由识图大智能服务解析订单信息，核对无误点击确认入账；修正数据：在收入流水页点击订单进入编辑，或删除录错的订单，首页与统计同步刷新；经营回顾：在日历统计查看每日明细，在数据洞察查看收入、利润、客单价与趋势图表。

## 十六、常见问题解答

问题：首次识别订单为什么慢？
解决方法：首次使用需要下载或初始化中文 OCR 识别智能服务，同时大智能服务解析需要联网请求，之后识别速度会明显加快。

问题：识别出的里程耗时与实际不符怎么办？
解决方法：确认预览阶段可直接修改里程与耗时字段，也可点击重新估算，入账后仍可在流水页进入编辑修正。

问题：换手机怎么保留账本数据？
解决方法：先在设置页导出备份文件，把文件传给新手机后在设置页导入，或直接打开收到的备份文件导入。

问题：两个大智能服务必须都配置吗？
解决方法：识别订单必须配置识图大智能服务；如只想手动记账不估算里程，可暂不配置识路大智能服务，但里程估算与识图补充计算将不可用。

问题：数据会上传到服务器吗？
解决方法：不会，订单数据全部保存在手机本地，只有调用大智能服务解析时会发送必要的图片文字与地点信息。
