🟢 改动： padding 增大，字体整体放大，space-between 垂直填满
旧版问题：
• padding 只有 14dp → 内容四周留白过多
• 左侧面板是一个容器，内容全堆在顶部 → 底部大片空白
• 右侧订单列表同理，3 条订单挤在最上面 → 下方空白
• 主金额只有 24sp，订单行 10sp → 字号偏小

优化方案：
• padding 14dp → 18dp（更紧贴外框）
• 左侧/右侧容器改用 space-between 垂直分布：头部-主体-底部分开
• 主金额：24sp → 32sp（约放大 33%），¥符号 13→17sp
• 标题：11sp → 13sp，日期 9→11sp，标签 9→11sp
• 次级指标（3单/客单价）：10sp → 12sp
• 订单列表文字：10sp → 12sp，金额 10→13sp，圆点 8→10dp
• 订单行间距 3dp → 4dp，分布更舒展
