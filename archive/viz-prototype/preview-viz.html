模块 ①

出行路网拓扑图

在高德底图上，把每条行程画成起点→终点的贝塞尔曲线：青→橙渐变表方向，线宽/深浅表频次或收入，标记大小表地点热度。一眼看出你的运营半径与主动脉：西流湖 → 省肿瘤医院这条黄金线在图上自然浮出。

读数：180 个地点 · 98 条线路 · 最热线路 14 单；白描边曲线保证可见度；高德原生手势缩放/拖拽/捏合，悬停显示明细，点击地点筛选相关线路、点击线路查看汇总（预览可体验）。

模块 ②

常去地点词云

起点与终点合并在一张云图里，字号 = 出现频率，颜色区分上车（青）/下车（橙）。"碧桂园西流湖名城"与"省肿瘤医院"会以最大字号占据视觉中心。可切换只看起点或只看终点，点击词语显示具体次数。

实现：Canvas 本地排版（螺旋防重叠算法），无第三方库。

黄金线路榜

读数：仅展示 ≥2 单的线路（当前 3 条），TOP1 碧桂园西流湖名城 → 省肿瘤医院 14 单；零散单不计入榜单。

高德 API 调用与缓存

订单起终点文字 → POI 检索（region=郑州，失败退地理编码）得到坐标与区县 → 写入备份 JSON 的 placeCache 字段永久缓存，同名地点去重合并（本次 197 → 180）。底图用静态地图 API 取一张 PNG，之后每次打开不再消耗 API 配额。

本次设计共消耗 POI 检索约 200 次（已全部完成并缓存），正式版仅在新增地点时增量调用。

技术要点与改动范围

  • 交互地图已落地：你提供的 Web 端(JS API) Key + 安全密钥已接入（JS API 2.0，明文 jscode 方式），底图用 whitesmoke 浅色样式贴合暖纸主题。
  • 坐标缓存：地理编码结果写入备份 JSON（新增 placeCache 字段），只请求一次，之后完全离线可用。
  • 改动点：index.html 新增 tab、JS API 接入与 6 个渲染函数；android-app assets 同步（WebView 需开启 WebGL/JS DOM storage）；数据管线复用 recalc 的 amapGet。
  • 图片导出：每个模块相机按钮 → html2canvas 截卡片 → 复用现有 Android.shareImage 分享/保存。
  • 异常防御：OCR 起终点缺失/乱文（如"单笔奖励"）自动跳过；解析失败的地点不上图但计入提示。
  • 双层兜底：JS API 加载失败/断网时自动回退"静态底图 + SVG 拓扑"方案，两种模式共用同一套数据与筛选逻辑；导出长图已配置 WebGL preserveDrawingBuffer。
