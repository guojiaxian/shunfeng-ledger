# 业务理解

- 软件名称：顺风账本软件
- 产品定位：顺风账本是一款面向网约车/顺风车司机的个人经营收支记账 Android 应用，通过拍照识别订单截图自动入账，并提供里程估算与经营数据统计，满足司机日常记账与经营分析需求。
- 面向领域 / 行业：出行服务配套软件 / 网约车顺风车司机个人经营记账工具
- 核心价值：司机每天接到大量平台订单，逐笔手动登记耗时费力。本软件通过智能大模型识别订单截图，自动提取车费、时间、起终点、人数、拼座/独享等信息并一键入账，同时提供里程/耗时估算与多维经营统计，全部数据本地存储、不上传服务器。
- 证据文件：`业务理解证据.md`

## 目标用户

- 使用滴滴、高德等顺风车平台接单的网约车/顺风车司机
- 单日订单量较大、需要快速记账并了解自身收入、利润、里程等经营情况的独立司机

## 主要业务功能

- 订单截图智能识别录入
- 里程与耗时估算
- 订单台账管理
- 首页经营看板
- 收入流水列表
- 日历统计
- 数据洞察统计
- 出行足迹分析
- 桌面小组件
- 数据备份与恢复
- 大模型引擎配置

## 功能说明

- 订单截图智能识别录入：拍摄或选择平台订单截图，先由 OCR 读取图中文字，再由识图大模型解析出日期、时间、车费、奖励、起终点、人数、拼座/独享等级别信息，结果经用户一次确认即可入账。
- 里程与耗时估算：识别或录入的订单由识路大模型根据地名与时间估算开车里程与耗时，高峰时段自动标注，估算结果可直接编辑修正后再保存。
- 订单台账管理：支持手动新增、编辑、删除订单，录入时自动检测与已有订单是否重复并提示，订单字段包括日期、时间、平台、车费、奖励、起终点、人数、车型类型、里程、耗时等。
- 首页经营看板：首屏展示今日订单数、今日收入（含整数/小数拆分展示）、与昨日环比、本周与本月累计收入与出车天数，顶部横幅随订单变化实时刷新。
- 收入流水列表：按日期分组展示全部订单，每条订单显示平台色点、起终点、金额、每公里单价，支持按平台筛选、按时间排序，可进入编辑或删除。
- 日历统计：以月日历形式展示每日订单数与收入，切换月份查看历史记录，点击某一天可查看当日订单明细。
- 数据洞察统计：统计范围内展示总收入、总利润、客单价、总里程、总单数、总天数等核心指标，并呈现高德/滴滴平台收入占比、趋势折线图、里程与耗时分布图，支持按近N天切换统计范围。
- 出行足迹分析：基于全部订单起终点生成常用地点词云（可切换单数/收入模式、支持放大拖拽缩放全屏）、出行路网地图（高德地图绘制上下车线路与地点节点）、黄金线路榜（高频上下车地点组合）与地点管理（查看上下车次数、重新定位、合并地点别名）。
- 桌面小组件：添加后无需打开应用即可查看今日收入、订单数与最近订单列表，点击小组件可跳转到记一笔、统计、日历或流水等对应页面。
- 数据备份与恢复：一键导出全部数据为 JSON 备份文件，支持从备份文件恢复，也支持从微信收到的 JSON 文件直接导入。
- 大模型引擎配置：设置页可分别配置识图/识路两个大模型的接口地址、模型名称与 API Key，预设提示词可直接查看与修改，提供一键连接测试验证配置是否可用，另可配置每公里电耗用于利润估算。

## 典型操作流程

1. 首次使用：先进入设置页配置识图与识路大模型，分别填入接口地址、模型名称与 API Key 并完成连接测试。
2. 日常入账：从首页拍摄或选择订单截图，OCR 读取文字后由识图大模型解析订单信息，核对无误点击确认入账。
3. 修正数据：在收入流水页点击订单进入编辑，或删除录错的订单，首页与统计同步刷新。
4. 经营回顾：在日历统计查看每日明细，在数据洞察查看收入、利润、客单价与趋势图表。
5. 地点分析：在出行足迹查看地点词云、路网地图与黄金线路榜，必要时重新定位或合并地点。
6. 数据保护：定期在设置页导出 JSON 备份，换机或重装时通过导入或微信文件恢复数据。

## 操作手册结构建议

1. 本软件面向滴滴、高德等平台顺风车/网约车司机的日常记账与经营分析，操作对象为手机上的订单截图、订单记录与统计图表。
2. 软件主要页面包括设置、首页看板、记一笔、收入流水、日历统计、数据洞察与出行足迹，功能入口以底部标签栏为主，设置入口在首屏右上角。
3. 用户每天的操作流程通常为：拍单/选图识别入账，在流水页核对或修改，在统计页查看当天收入与长期趋势，必要时导出备份。

## 操作手册页面/流程模块

1. 配置大模型引擎：启动软件后点击首屏右上角设置入口进入设置页，在设置页中上下滑动找到识别引擎相关配置区。
   - 使用场景：司机第一次安装软件，或在更换大模型服务商、接口地址变化后，需要设置正确的接口地址、模型名称和 API Key。
   - 操作要点：进入设置页，找到识图大模型配置分组。；在接口地址、模型名称、API Key 三个输入框中分别填入大模型服务信息。；核对预设提示词，按需查看或修改识别规则。；点击连接测试按钮，等待连通性检测结果。
2. 识别订单截图：首页点击识别订单按钮，或通过页面提供的选择与拍摄入口选取订单截图。
   - 使用场景：司机完成一单出行后，拍下或截取平台订单完成页，希望快速把车费、时间、起终点等信息记入账本。
   - 操作要点：在首页点击识别订单。；拍摄一张订单截图，或从相册选择已有截图。；等待 OCR 读取图片文字，首次使用需等待中文识别模型加载。；大模型解析出订单信息后在确认预览卡片中逐项展示。
3. 手工记一笔：首页点击记一笔按钮，或点击流水列表中已有订单进入编辑。
   - 使用场景：订单截图模糊无法识别、司机想手动补录历史订单、或对识别结果进行修正时使用。
   - 操作要点：打开记一笔弹窗。；填写日期、时间并选择平台。；输入总车费与奖励金额。；填写起点与终点。
4. 首页经营看板：启动软件即显示首页看板。
   - 使用场景：司机每天打开软件的第一屏，用于快速了解今天接了多少单、赚了多少、相比昨日是升是降，以及本周本月的累计情况。
   - 操作要点：启动软件查看今日订单数与今日收入。；查看与昨日对比的涨跌情况。；查看本周、本月累计收入与出车天数。
5. 收入流水：点击底部标签栏的流水标签进入收入流水页。
   - 使用场景：司机需要回顾某天接了多少单、核对某笔订单金额是否录错、或修正起终点与里程时使用。
   - 操作要点：进入流水页查看分组订单。；按平台筛选查看高德或滴滴订单。；点击某条订单查看详情或进入编辑。；对录错的订单执行删除操作。
6. 日历统计：点击底部标签栏的日历标签进入日历统计页。
   - 使用场景：司机想查看某一天或某一月接了多少单、收入多少，特别是隔几天后的补录与核对。
   - 操作要点：进入日历页查看当前月每日订单与收入。；切换上个月或下个月回顾历史。；点击带数据的日期查看当日订单明细。
7. 数据洞察：点击底部标签栏的统计标签进入数据洞察页。
   - 使用场景：司机想了解最近 7 天、30 天或更长周期的总收入、利润、客单价、里程与平台构成，判断经营成效。
   - 操作要点：进入数据洞察页。；选择统计范围（如近7天、近30天）。；查看总利润、客单价等核心指标。；查看高德与滴滴收入占比与每日趋势。
8. 出行足迹：点击底部标签栏的足迹标签进入出行足迹页。
   - 使用场景：司机想看看自己经常在哪里接单上车、在哪里下车，哪些线路跑得最多，或对地点坐标进行核对调整。
   - 操作要点：进入足迹页查看地点词云，切换按单数或按收入排序。；查看出行路网地图上的上下车地点分布。；查看黄金线路榜了解高频线路。；进入地点管理核对地点定位，对定位不准的地点重新定位，对同一地点的不同叫法执行合并。
9. 桌面小组件：在手机桌面长按空白处选择添加小组件，找到顺风账本小组件添加到桌面。
   - 使用场景：司机不想频繁打开软件，通过桌面小组件一眼查看今天赚了多少、接了多少单。
   - 操作要点：在手机桌面长按进入添加小组件界面。；找到顺风账本小组件并添加到桌面。；查看今日收入、订单数与最近订单。；点击小组件跳转到对应功能页面。
10. 数据备份与恢复：设置页提供导出备份与从备份导入入口，也支持从微信接收的 JSON 文件直接导入。
   - 使用场景：司机更换手机、重装软件或担心数据丢失时，先导出备份，再在新设备或重新安装后导入恢复。
   - 操作要点：在设置页点击导出备份，选择保存位置。；将备份文件发送到新手机（如通过微信）。；在新设备上打开收到的备份文件或从文件导入。；确认导入后数据完整恢复。

## 申请表建议口径

- 开发目的：解决网约车顺风车司机逐笔手记订单耗时费力、收入利润难以核算的问题，提供从订单识别入账到经营统计的完整记账闭环。
- 软件的主要功能：订单截图 OCR 文字识别、大模型解析订单信息与里程耗时估算、订单新增编辑删除与重复检测、今日/本周/本月收入看板、收入流水分组展示与筛选、日历视图历史订单查询、收入利润客单价里程统计与趋势图表、出行足迹词云与路网地图与线路榜与地点管理、桌面小组件实时数据展示、数据导出导入备份恢复、识图识路大模型引擎配置与连接测试、电耗成本配置与利润估算。
