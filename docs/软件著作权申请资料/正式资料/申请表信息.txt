➤软件的主要功能：顺风账本是一款面向网约车/顺风车司机的个人经营收支记账 Android 应用，通过拍照识别订单截图自动入账，并提供里程估算与经营数据统计，满足司机日常记账与经营分析需求。软件主要提供订单截图智能识别录入、里程与耗时估算、订单台账管理、首页经营看板、收入流水列表、日历统计、数据洞察统计、出行足迹分析等功能。司机每天接到大量平台订单，逐笔手动登记耗时费力。本软件通过智能大模型识别订单截图，自动提取车费、时间、起终点、人数、拼座/独享等信息并一键入账，同时提供里程/耗时估算与多维经营统计，全部数据本地存储、不上传服务器。订单截图智能识别录入功能主要拍摄或选择平台订单截图，先由 OCR 读取图中文字，再由识图大模型解析出日期、时间、车费、奖励、起终点、人数、拼座/独享等级别信息，结果经用户一次确认即可入账。里程与耗时估算功能主要识别或录入的订单由识路大模型根据地名与时间估算开车里程与耗时，高峰时段自动标注，估算结果可直接编辑修正后再保存。订单台账管理功能主要支持手动新增、编辑、删除订单，录入时自动检测与已有订单是否重复并提示，订单字段包括日期、时间、平台、车费、奖励、起终点、人数、车型类型、里程、耗时等。首页经营看板功能主要首屏展示今日订单数、今日收入（含整数/小数拆分展示）、与昨日环比、本周与本月累计收入与出车天数，顶部横幅随订单变化实时刷新。收入流水列表功能主要按日期分组展示全部订单，每条订单显示平台色点、起终点、金额、每公里单价，支持按平台筛选、按时间排序，可进入编辑或删除。日历统计功能主要以月日历形式展示每日订单数与收入，切换月份查看历史记录，点击某一天可查看当日订单明细。数据洞察统计功能主要统计范围内展示总收入、总利润、客单价、总里程、总单数、总天数等核心指标，并呈现高德/滴滴平台收入占比、趋势折线图、里程与耗时分布图，支持按近N天切换统计范围。出行足迹分析功能主要基于全部订单起终点生成常用地点词云（可切换单数/收入模式、支持放大拖拽缩放全屏）、出行路网地图（高德地图绘制上下车线路与地点节点）、黄金线路榜（高频上下车地点组合）与地点管理（查看上下车次数、重新定位、合并地点别名）。用户通常先首次使用：先进入设置页配置识图与识路大模型，分别填入接口地址、模型名称与 API Key 并完成连接测试，再日常入账：从首页拍摄或选择订单截图，OCR 读取文字后由识图大模型解析订单信息，核对无误点击确认入账，再修正数据：在收入流水页点击订单进入编辑，或删除录错的订单，首页与统计同步刷新，再经营回顾：在日历统计查看每日明细，在数据洞察查看收入、利润、客单价与趋势图表，再地点分析：在出行足迹查看地点词云、路网地图与黄金线路榜，必要时重新定位或合并地点，再数据保护：定期在设置页导出 JSON 备份，换机或重装时通过导入或微信文件恢复数据，系统在关键步骤提供状态反馈和结果展示。
